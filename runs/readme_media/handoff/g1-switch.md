## Verified
**Power, measured live.**
- Start, 04:23: `pmset -g batt` gave "Battery Power", 79 %, discharging; `pmset -g` gave `powermode 2`; queue empty;
  `hw.model` Mac16,6.
- End, 05:07: battery, 49 %, discharging; `powermode 2`; queue empty.
- `pmset -g custom` shows `powermode 2` for both the AC and the battery profile.
- `system_profiler SPPowerDataType` said "Low Power Mode: Yes, High Power Mode: No". Per Apple DTS
  (https://developer.apple.com/forums/thread/835131) that field is the current state, which an idle machine also
  reports, while pmset gives the configured setting. So the stamp uses pmset.
- `pmset`'s man page does not document `powermode`. "2 = High Power" rests on that forum thread's original post.
- `parse_power` was tested on the live output and on samples: AC charged, AC attached / not charging, both keys,
  desktop, empty input, unknown value.
