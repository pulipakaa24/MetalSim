# docgen-sync: the film doc stage writes the corrected docs

## Status
**Done.** `--stage doc` now reproduces the hand-corrected docs for all five films this stream owns: franka_pour,
g1_flat, g1_rough, g1_unitree and tron1. A second run changes nothing. Stage-written facts in the notes now come from
the stage logs: power, day, machine, metalsim commit, MuJoCo Warp and Warp commits against their pins, re-render time,
and floor tile. CPU only; no GPU job was run. Nothing is committed.

How it works:
- `FilmTask.notes` may now be a callable `notes(take) -> str`.
- The doc stage passes it a `doc.Take` built from rec.json and each render.json.
- String notes are printed as before. G1_BUMPS and SO101 keep string notes, and their output is unchanged (checked,
  see Verified 4).

"gen0" is what `--stage doc` wrote before this change; "now" is what it writes after. Both are compared with the doc as
it stood at session start.

|---|---|---|

| TRON1 | reverted both corrections: the MuJoCo Warp / Warp / identical-take sentence; power said AC 14:38 instead of battery 69/69/66 % 16:05/16:05/16:07 | same words; "This take" refilled (24 lines, whitespace only) |
| G1_FLAT, G1_ROUGH | would have added "at its real size, 1.70 m per image, eight 21 cm planks" to takes rendered at the old 4.0 m tile (50 cm planks), which is false | same words; "This take" refilled (24 lines, whitespace only) |
| FRANKA_POUR | added the power line and the false "real size, 1.70 m" claim; that take was drawn at 2.0 m and has no tile or cache key in its logs | +1 line: "Power as each stage stamped it ... record: not recorded; render hero: not recorded; render grid: not recorded." |

The Franka line is a justified difference. The generator has written it since `dfec9ebf`, the stage logs from
2026-10-21 have no power stamps, and the statement is true. The doc had simply not been regenerated since.

Why the "This take" paragraphs are refilled:
- Their machine, day, commits and power are interpolated now, so a hand-wrapped template cannot know the widths.
- The hand edits had left lines of 400+ characters.
- `Take.fill` wraps at 120 and never starts a line with "- ", "2. ", "#" or ">".
- A soft line break renders as a space, so the rendered page is the same.
